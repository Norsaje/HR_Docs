## Условия допуска Д1–Д12

| Д | Как показываем | Чем проверено | Статус |
|---|---|---|---|
| Д1 | `git clone` → `.env` → `make secrets` → `docker compose up -d --build` по README | прогон README на чистом клоне (фаза 4) | частично: стенд поднимается, README ещё нет |
| Д2 | Отдельный FastAPI, проверки приёма в `app/intake` | тесты приёма через API (фаза 1) | частично: есть только каркас |
| Д3 | Два своих React-приложения | `make e2e-smoke` (фаза 1) | нет |
| Д4 | `docker compose restart` → заявки на месте | шаг e2e (фаза 1) | частично: volume pg_data/s3_data есть |
| Д5 | Журнал: провайдер, модель, длительность каждого разбора | эксперименты фазы 0 через шлюз | частично |
| Д6 | `app/llm/`, `LLM_BASE_URL`, профиль `llm-local`, `docs/local-model.md` | тесты шлюза (respx), `make llm-smoke` | частично |
| Д7 | 20 файлов, kill воркера, всё дошло | `make restart-drill` (фаза 1) | нет |
| Д8 | `curl` без cookie → 401, чужой офис → 404 | `tests/test_security.py` (фаза 1) | нет |
| Д9 | История коммитов, gitleaks | `gitleaks git` в pre-commit на каждом коммите | частично |
| Д10 | `README.md`, `docs/*.md` | чек-лист (фаза 4) | частично: decisions, limitations — черновики |
| Д11 | Восемь видов на открытом наборе | `make eval` (фаза 2) | нет |
| Д12 | Карта владения, `docs/how-to-change.md` | люди читают свой модуль | частично: docstring в каждом модуле |
