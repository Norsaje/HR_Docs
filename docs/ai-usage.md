## Какие ассистенты

- **Claude Code** (модель Claude Opus) — основной кодинг-агент: работал по `AGENTS.md`, `docs/TASKS.md` и спецификации `docs/spec/`, фаза за фазой; в аварийном режиме — с параллельными субагентами (фронтенд соискателя, фронтенд оператора, документация).
- Модели внутри продукта (Qwen3.8, olmOCR) — не ассистенты разработки, а часть решения (`docs/local-model.md`).

## Где ассистент ошибся и как заметили

Случаи, которые нашлись в ходе работы (люди — дополните своими):

- **Блокировка админки Keycloak в Caddy не работала**: конфигурация из спецификации (`respond @kc_private 404`) пропускала `/kc/realms/master` (200), потому что Caddy выполняет `handle` раньше `respond`. Заметили проверкой маршрутов curl'ом; исправлено через `handle @kc_private`.
- **Фильтр секретов в логах вырезал бы метрики**: первая версия искала подстроку `token`, под неё попадали `tokens_in/tokens_out`. Заметили при чтении кода, исправлено на точные имена и суффиксы, добавлен тест.
- **Тестовый ключ Fernet литералом** — gitleaks в pre-commit остановил коммит; ключ теперь строится в коде.
- **`ruff format` на корне репозитория переформатировал примеры кода в спецификации** (`docs/spec/*.md`) — заметили по `git diff`, откатили, Markdown исключён из ruff.
- **Ошибка в исходном реестре** (подпись поля с запятой без кавычек) — нашёл не агент, а загрузчик реестра с Pydantic-валидацией при первом запуске.
