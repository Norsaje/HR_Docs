# Как запустить агента (для команды)

1. Создайте пустой репозиторий (GitHub или GitVerse). Сразу дайте доступ судьям: кейс требует, чтобы он был создан в начале работы.
2. Распакуйте содержимое этого архива в корень репозитория. `START.md` можно не коммитить.
3. Положите открытый набор документов в `data/open/` (папка в `.gitignore`).
4. На машине, где работает агент, нужны Docker, Docker Compose, `uv`, Node 22 и `git` с вашим именем:
   ```bash
   git config user.name "Имя Фамилия"
   git config user.email "you@example.com"
   ```
5. Создайте `.env` из `.env.example` и впишите ключ модели (`LLM_API_KEY` = ваш `ILONS_API_KEY`) и, если выдали, `OCR_API_TOKEN`. Остальные секреты агент сгенерирует сам (`make secrets`). IP стенда пишется только в `.env` на сервере.
6. Запустите Claude Code в корне репозитория и дайте первую команду:

   > Прочитай AGENTS.md и docs/TASKS.md. Работай автономно по фазам 0–5, соблюдая гейты. Коммить маленькими шагами. После каждой фазы коротко отчитывайся: что сделано, что проверено, какие решения записаны в docs/decisions.md. Фазу 6 не начинай без моей команды.

7. Пока агент работает, люди делают то, что агент сделать не может:
   - **разметка эталона.** Размечайте открытый набор в `eval/gold/` (формат — в `docs/spec/10-eval-ops.md`), по одному виду документов на человека;
   - **ревью своих модулей.** Карта владения — в `docs/TASKS.md`. Каждый читает и коммитит свой участок — это требование Д12 и «Владения решением»;
   - **журнал решений.** Переписывайте записи в `docs/decisions.md` своими словами по мере появления;
   - **вопросы к организаторам** (ниже) — ответы сразу передавайте агенту.
8. Когда MVP готов и нужно передать работу людям, скажите агенту:
   > Выполни фазу 6 из docs/TASKS.md: подготовь docs/handoff/backend.md и docs/handoff/frontend.md по фактическому коду.

## Что спросить у организаторов (влияет на код)

- Можно ли включить токен на ocr.ilons.ru (`OCR_CLIENT_TOKEN`) и какой у него лимит параллельных запросов?
- Достаточно ли на защите показать переключение адреса модели: llm.ilons.ru → vLLM на A10?
- Откроют ли на защите 443 на GPU-сервере (для телефонов судей) или показываем через SSH-туннель?
- Патент: откуда брать «действует до», если на бланке поля нет? Миграционная карта: «действует до» — это «срок пребывания до»?
- Паспорт Узбекистана — загранпаспорт или ID-карта? «Вид на жительство» в блоке «Европа» — российский ВНЖ или карта страны ЕС?
- Как считается точность поля (нормализация дат, ФИО, серии с пробелом)?
